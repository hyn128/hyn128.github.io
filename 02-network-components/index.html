1. 네트워크 규모에 따른 분류

개요

네트워크는 연결 범위와 관리 영역에 따라 LAN(Local Area Network), MAN(Metropolitan Area Network), WAN(Wide Area Network)으로 구분한다.

과거에는 각 네트워크에서 사용하는 프로토콜과 기술이 서로 달랐기 때문에 기술적인 차이로도 구분할 수 있었다. 그러나 현재는 대부분 Ethernet 기반으로 통합되면서 관리 범위와 구축 방식을 기준으로 구분하는 경우가 많다.

강의에서는 다음과 같이 구분하였다.

  • 자체 인프라를 구축하여 운영하는 경우 → MAN
  • 통신 사업자의 인프라를 이용하는 경우 → WAN

네트워크 종류

구분 범위 특징
LAN (Local Area Network) 건물, 사무실 등 소규모 내부 네트워크
MAN (Metropolitan Area Network) 도시 단위 자체 인프라 기반
WAN (Wide Area Network) 국가·지역 간 통신사 회선 이용

LAN (Local Area Network)

LAN은 비교적 좁은 범위에서 사용하는 네트워크이다.

주로 기업 내부나 학교, 건물 등 하나의 관리 영역 안에서 사용되며, 스위치와 같은 간단한 네트워크 장비를 이용해 구성한다.

특징

  • 소규모 네트워크
  • Ethernet 기반 전송 기술 사용
  • Switch를 이용한 내부 연결
  • 직접 구축한 케이블과 장비를 이용해 운영

과거에는 Ethernet 외에도 다양한 LAN 기술이 존재했지만 현재는 대부분 Ethernet으로 통합되었다.

WAN (Wide Area Network)

WAN은 서로 멀리 떨어진 LAN을 연결하기 위한 네트워크이다.

일반적으로 기업이 직접 회선을 구축하기보다는 통신 사업자로부터 회선을 임대하여 사용한다.

특징

  • 원거리 네트워크 연결
  • 서로 다른 LAN 연결
  • 인터넷 연결
  • 통신 사업자의 회선 이용

정리

  • LAN은 내부 네트워크를 의미한다.
  • WAN은 원거리 네트워크를 연결하기 위한 네트워크이다.
  • 현재는 대부분 Ethernet 기반으로 통합되어 관리 범위를 기준으로 구분한다.

2. 인터넷 회선

일반 인터넷 회선

일반 인터넷 회선은 사용자가 인터넷에 접속하기 위해 통신 사업자(ISP)와 연결하는 가장 일반적인 형태의 회선이다.

가입자와 통신 사업자가 1:1로 직접 연결되는 구조가 아니라, 여러 사용자가 하나의 전송 회선을 공유하는 방식으로 운영된다.

이를 위해 다중화(Multiplexing) 기술을 사용한다.

특징

  • 회선을 여러 사용자가 공유
  • 가입자와 통신 사업자가 직접 연결되는 구조는 아님
  • 계약한 속도는 최대 속도(Best Effort)
  • 실제 속도는 네트워크 상황에 따라 달라질 수 있음

전용 회선 (Leased Line)

전용 회선은 가입자와 통신 사업자 사이의 대역폭(Bandwidth)을 보장하는 회선이다.

일반 인터넷 회선과 달리 다른 사용자와 회선을 공유하지 않기 때문에 안정적인 성능을 제공한다.

대표적으로 TDM(Time Division Multiplexing, 시분할 다중화) 기술을 이용하여 일정한 대역폭을 보장한다.

LLCF (Link Loss Carry Forward)

LLCF는 한쪽 링크가 끊어진 것을 감지하면 반대편 링크도 함께 종료시키는 기능이다.

강의에서는 온라인 게임 서버가 사용자의 연결 상태를 지속적으로 확인(Ping)하고, 응답이 없으면 연결을 종료하여 새로운 사용자가 접속할 수 있도록 하는 사례를 예로 설명하였다.

인터넷 전용 회선

인터넷 전용 회선은 인터넷에 연결하면서도 계약한 통신 대역폭을 보장받을 수 있는 서비스이다.

일반 인터넷 회선보다 안정적인 품질과 일정한 속도를 제공한다.

VPN (Virtual Private Network)

VPN은 공용 네트워크를 이용하면서도 전용 회선처럼 사용할 수 있도록 만든 가상의 사설망이다.

구현 방식에 따라 크게 통신 사업자 VPN과 가입자 VPN으로 구분할 수 있다.

통신 사업자 VPN

전용 회선은 항상 계약한 대역폭을 보장하지만, 사용자가 항상 모든 대역폭을 사용하는 것은 아니다.

이 때문에 사용하지 않는 대역폭에도 비용을 지불해야 하는 비효율이 발생할 수 있다.

이를 해결하기 위해 통신 사업자는 하나의 공용망을 여러 가입자가 함께 사용하도록 하면서도, 가입자별 트래픽을 논리적으로 분리하는 기술을 제공한다.

대표적인 기술이 MPLS VPN(Multiprotocol Label Switching VPN) 이다.

특징

  • 공용망 사용
  • 가입자별 트래픽 논리적 분리
  • 전용선과 유사한 연결 환경 제공
  • 전용선보다 비용 절감 가능
  • 여러 지점을 연결하는 기업 환경에서 많이 사용

가입자 VPN

가입자 VPN은 인터넷과 같은 공용망 위에서 암호화를 이용해 가상의 사설망을 구성하는 방식이다.

별도의 전용선을 설치하지 않아도 안전하게 내부 네트워크에 접속할 수 있다.

특징

  • 인터넷 기반
  • 데이터 암호화
  • 저렴한 구축 비용
  • 원격 근무 및 재택근무 환경에서 많이 사용

대표적인 기술은 다음과 같다.

  • IPsec VPN
  • SSL VPN
  • OpenVPN
  • WireGuard

VPN과 일반 인터넷의 속도

강의에서는 VPN이 목적지 정보를 알고 있어 보다 효율적인 라우팅 경로를 사용할 수 있기 때문에, 암호화와 복호화 과정이 추가되더라도 일반 인터넷보다 빠른 경우가 있다고 설명하였다.

정리

  • 일반 인터넷은 회선을 공유한다.
  • 전용 회선은 대역폭을 보장한다.
  • VPN은 공용망을 이용해 전용선과 유사한 환경을 제공한다.
  • VPN은 통신 사업자 VPN과 가입자 VPN으로 구분할 수 있다.

3. 네트워크 구성 요소

NIC (Network Interface Card)

NIC(Network Interface Card)는 컴퓨터를 네트워크에 연결하기 위한 네트워크 인터페이스 장치이다.

최근에는 대부분 메인보드에 온보드(On-board) 형태로 내장되어 있어 별도의 NIC를 장착하는 경우는 많지 않다.

주요 역할

직렬화(Serialization)

컴퓨터 내부의 데이터와 네트워크에서 사용하는 전기 신호를 서로 변환한다.

강의에서는 항공기나 선박의 블랙박스를 예로 들어, 저장된 데이터를 제조사의 전용 형식으로 해석해야 하는 것처럼 데이터를 특정 형식으로 변환하는 과정의 중요성을 설명하였다.

MAC Address

NIC는 장비 고유의 물리적 주소인 MAC(Media Access Control) 주소를 가진다.

2계층 통신에서는 이 MAC 주소를 이용하여 통신 상대를 구분한다.

Flow Control

Flow Control은 송신 장치의 전송 속도와 수신 장치의 처리 속도를 맞추기 위한 기능이다.

수신 장치가 더 이상 데이터를 처리할 수 없는 경우 송신 측에 전송을 잠시 중지하도록 요청한다.

강의에서는 과거 온라인 게임에서 느린 모뎀을 사용하는 사용자가 전체 게임 진행에 영향을 주던 사례를 예로 설명하였다.

케이블과 커넥터

Ethernet에서는 사용하는 케이블 종류에 따라 서로 다른 규격을 사용한다.

대표적인 표기 방식은 다음과 같다.

규격 의미
1000BASE-T 1000Mbps, Twisted Pair 케이블 사용
10GBASE-T 10Gbps, Twisted Pair 케이블 사용
1000BASE-SX 1000Mbps, 광케이블 사용
10GBASE-SR 10Gbps, 광케이블 사용

규격 이름에는 전송 속도와 사용하는 전송 매체가 함께 포함되어 있다.

Hub

Hub는 OSI 1계층(Physical Layer)에서 동작하는 장비로, 여러 장비를 하나의 네트워크로 연결하는 역할을 한다.

본질적으로는 케이블을 연장하는 장치와 유사하며, 약해진 전기 신호를 재생성(Repeating)하여 전달한다.

특징

  • OSI 1계층 장비
  • 여러 장비를 하나의 네트워크에 연결
  • 들어온 전기 신호를 모든 포트로 전달(Broadcast)
  • 목적지 주소를 구분하지 못함

Hub는 어느 포트에서 데이터가 들어왔는지와 관계없이 입력 포트를 제외한 모든 포트로 동일한 신호를 전달한다.

이 때문에 네트워크에 연결된 모든 장비가 동일한 신호를 처리해야 하므로 네트워크 효율이 떨어진다.

또한 여러 장비가 동시에 데이터를 전송하려고 경쟁하게 되어 성능이 저하될 수 있으며, 패킷이 계속 순환하는 루프(Loop)와 같은 장애가 발생할 수도 있다.

Switch

Switch는 여러 장비를 연결한다는 점에서는 Hub와 같지만, OSI 2계층(Data Link Layer)에서 동작하는 장비이다.

MAC 주소를 이해하고 학습하여 필요한 포트로만 데이터를 전달할 수 있기 때문에 Hub보다 훨씬 효율적으로 통신을 수행한다.

Switch를 Switching Hub라고 부르기도 한다.

특징

  • OSI 2계층 장비
  • MAC 주소 인식
  • MAC 주소 학습(MAC Learning)
  • Unicast 기반 통신
  • 불필요한 Broadcast 감소

Switch는 처음 통신이 발생하면 출발지 MAC 주소와 연결된 포트를 MAC Address Table에 저장한다.

이후 같은 장비로 데이터를 전송할 때는 모든 포트로 전송하는 대신 해당 장비가 연결된 포트로만 데이터를 전달한다.

이러한 방식을 Unicast라고 하며, Hub의 Broadcast 방식보다 네트워크 효율이 훨씬 높다.

Router

Router는 서로 다른 네트워크를 연결하는 OSI 3계층(Network Layer) 장비이다.

IP 주소를 이용하여 목적지 네트워크를 찾고 최적의 경로를 선택하여 패킷을 전달한다.

특징

  • OSI 3계층 장비
  • 서로 다른 네트워크 연결
  • IP 주소 기반 라우팅
  • Broadcast와 Multicast 제어
  • 최적의 경로 선택 및 Forwarding

Router는 내부 네트워크에서 발생한 Broadcast가 외부 네트워크로 무분별하게 전달되지 않도록 제어한다.

또한 목적지가 명확하지 않은 패킷은 폐기하며, 목적지까지 가장 적절한 경로를 선택하여 패킷을 전달한다.

최근에는 Router의 기능을 수행하는 Layer 3 Switch나 가정용 공유기도 널리 사용된다.

Load Balancer

Load Balancer는 여러 대의 서버에 트래픽을 분산하여 하나의 서버에 부하가 집중되는 것을 방지하는 장비이다.

일반적으로 OSI 4계층(Transport Layer)에서 동작하지만, 최근에는 애플리케이션 계층에서 동작하는 7계층 Load Balancer도 많이 사용된다.

특징

  • 4계층 또는 7계층에서 동작
  • 동일한 서비스를 제공하는 여러 서버에 요청 분산
  • 목적지 IP 주소 변경 가능
  • Health Check 수행
  • 대량의 세션 처리

4계층 Load Balancer는 IP 주소와 Port 정보를 이용하여 트래픽을 분산한다.

7계층 Load Balancer는 HTTP와 같은 애플리케이션 프로토콜까지 분석하여 더욱 세밀한 부하 분산이 가능하다.

강의에서는 이러한 7계층 장비를 원래 ADC(Application Delivery Controller) 라고 설명하였다.

보안 장비

보안 장비는 데이터를 전달하는 것이 아니라 네트워크를 보호하고 공격을 방어하는 데 목적이 있는 장비이다.

설치 위치와 방어 대상에 따라 다양한 종류가 존재한다.

대표적인 보안 장비는 방화벽(Firewall) 이다.

방화벽(Firewall)

방화벽은 일반적으로 OSI 4계층에서 동작하며, 패킷의 IP 주소와 Port 번호를 확인하여 보안 정책에 따라 허용하거나 차단한다.

특징

  • IP 주소 확인
  • Port 번호 확인
  • 보안 정책 비교
  • 허용 또는 차단
  • 필요한 경우 패킷 Forwarding 수행

공유기

공유기는 여러 네트워크 기능을 하나의 장비에 통합한 장비이다.

가정이나 소규모 사무실에서 가장 많이 사용되며, 내부적으로 여러 장비가 결합된 형태로 동작한다.

내부 구성

  • Layer 2 Switch
  • Router
  • Wireless Access Point
  • NAT(Network Address Translation)

즉, 공유기는 단순한 Router가 아니라 스위치와 무선 AP, NAT 기능 등을 함께 제공하는 복합 네트워크 장비이다.

모뎀

모뎀(Modem)은 서로 다른 통신 기술을 사용하는 네트워크를 연결하기 위한 장비이다.

가까운 거리와 먼 거리는 사용하는 전송 기술이 서로 다르므로, 모뎀은 이들 신호를 서로 변환하여 원거리 통신이 가능하도록 한다.

특징

  • 서로 다른 통신 기술 변환
  • 원거리 통신 지원
  • 전송 신호 변환 수행

정리

  • Hub는 1계층에서 Broadcast 방식으로 동작한다.
  • Switch는 MAC 주소를 이용하여 필요한 포트로만 데이터를 전달한다.
  • Router는 IP 주소를 이용해 최적의 경로를 선택한다.
  • Load Balancer는 여러 서버에 부하를 분산한다.
  • 방화벽은 IP와 Port 정보를 기반으로 패킷을 제어한다.
  • 공유기는 Switch, Router, NAT, 무선 AP 기능을 통합한 장비이다.
  • 모뎀은 서로 다른 통신 기술을 변환하여 원거리 통신을 지원한다.
