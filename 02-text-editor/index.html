vim, nano 등 Linux 텍스트 편집기 사용법 정리

Dohyeon Kim 2026년 7월 20일 · 3분 읽기

1 ) VIM editor

  • vi 이후 개발된 에디터

  • sudo apt install vim -y

  • vim {path} → 파일이 존재할 경우 내용 표시 → 존재하지 않을 경우 빈 파일 생성
    • 파일 경로를 생략하면 기본 화면 출력
    • 수정 권한이 없을 경우 읽기 전용으로 열림

      모드 전환

      1. 명령모드 → 입력모드: i I A A o O
      2. 입력모드 → 명령모드: esc

종료

  1. 명령 모드: :q, :q!, :w, :wq, :wq!
    • w가 붙으면 저장 후 종료, !는 강제 실행

커서 이동

  1. ^ → 현재 행의 맨 앞으로
  2. $ → 현재 행의 맨 뒤로
  3. H → 현재 화면의 맨 윗 행으로
  4. M → 현재 화면의 중간 행으로
  5. L → 현재 화면의 맨 뒷 행으로

화면 이동

  1. Ctrl + u → 반 화면 위로 이동
  2. Ctrl + d → 반 화면 아래로 이동
  3. Ctrl + b → 한 화면 위로 이동
  4. Ctrl + f → 한 화면 아래로 이동
  5. Ctrl + y → 한 행만 위로 이동
  6. Ctrl + e → 한 행만 아래로 이동

원하는 행으로 이동

  1. {num}G → 숫자 행으로 이동
  2. :{num} [enter] -> 숫자 행으로 이동
  3. :$: → 파일의 마지막 행으로 이동

내용 수정

  1. r → 한 글자 수정

  2. cw / #cw → 하나의 단어를 수정
    • # 대신 숫자 입력 시 숫자 단어 만큼 수정
  3. s / #s → esc를 입력할 때까지 수정
    • # 대신 숫자 입력 시 숫자 글자 수 만큼 수정
  4. cc → 현재 행의 내용을 전부 수정
  5. C → 커서 위치부터 행의 끝까지 수

## 내용 삭제

  1. x / #x → 글자 삭제
  2. dw / #dw → 단어 삭제
  3. dd / #dd → 행 삭제
  4. D → 커서 위치부터 행의 끝까지 삭제
    • # 대신 숫자 입력 시 숫자 단어 만큼 수정

명령 취소

  1. u → 명령을 취소
  2. U → 해당 행에서 한 모든 명령을 취소
  3. e! → 마지막으로 젖아한 내용 이후의 것을 버리고 새로 작업

    복사, 붙이기, 잘라내기

  4. yy / #yy → 커서가 위치한 행 복사
  5. p → 커서 아래 행에 붙이기
  6. P → 커서의 윗 행에 붙이기
  7. dd / #dd → 잘라내기
  8. 복사를 할 때 버퍼이름+yy를 사용하면 현재 행의 내용을 버퍼 이름으로 저장
  9. 붙여넣을 때는 버퍼이름 +p를 이용

내용 검색

  1. /{str} → 아래 방향으로 검색
  2. ?{str} → 위 방향으로 검색
  3. n → 검색 방향의 다음 검색 결과
  4. N → 검색 반대 방향으로 다음 검색 결과

치환

  1. :s/{str1}/{str2} → 커서가 위치한 행에서 문자열 1을 문자열 2로 치환

  2. %s/{str1}/{str2}/g → 문서 전체에서 문자열 1을 문자열 2로 치환

  3. % 대신 범위 설정 가능

  4. :set ignorecase → 대소문자 구분 없이 치환

  5. :%s/.*\L&/g → 대문자를 소문자로 변경
  6. :%s/.*\U/g → 소문자를 대문자로 변경

파일 읽어오기

  1. :r {path} → 지정한 파일을 읽어들여 현재 커서 위치에 삽입
  2. :e {path} → 기존 파일을 저장 하고 지정한 파일로 전환
  3. :n → 여러 파일을 지정했을 경우 vi 시작 시 다음 파일로 작업 이동

shell 명령 수행

  1. :! {cmd} → vi 작업 잠시 중단하여 명령어 실행 → Enter로 복귀
  2. :sh → vi를 잠시 빠져나가 명령어 실행 → exit로 복귀
  3. :n → 여러 파일을 지정했을 경우 vi 시작 시 다음 파일로 작업 이동

vim의 환경 설정

  1. 설정 방법 → 홈 디렉토리에 있는 .exrc 파일에 설정 내용 저장

  2. 환경 변수 EXINIT에 지정
  3. vim의 마지막 행 모드에서 명령으로 설정
  • 환경 설정 옵션
    • set nu → 행 번호 표시
    • set nonu → 행 번호 미표시
    • set list → 보이지 않는 특수문자 표시
    • set nolist → 보이지 않는 특수문자 미표시
    • set showmode → 현재 모드 표시
    • set noshowmode → 현재 모드 미표시
    • set → set으로 설정한 모든 vi 환경 설정 값 출력
    • set all → 모든 vi 환경 변수와 현재 값을 출력
    • set ai → 윗 라인과 동일한 들여쓰기
    • set si → 코딩 시 if / for를 입력하면 다음 라인에 자동으로 들여쓰기

2 ) NANO editor

개요

  • 메뉴 기반의 명령 줄 텍스트 편집기
  • 구문 강조 표시, 다중 버퍼, 검색 및 정규식 지원으로 일반 편집기에서 기대할 수 있는 모든 기능이 포함

설치 및 확인

  • nano --version
  • sudo apt install nano
