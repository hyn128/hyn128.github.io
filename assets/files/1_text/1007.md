import json
import boto3
from datetime import datetime

client = boto3.client('s3')

def lambda_handler(event, context):
    what_time = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    bucket = event['Records'][0]['s3']['bucket']['name']
    key = event['Records'][0]['s3']['object']['key']

    try:
        response = client.get_object(Bucket=bucket, Key=key)
        text = response['Body'].read().decode()
        data = json.loads(text)
        
        if data['temperature'] > 40:
            print(f" {data['temperature']} at {what_time}")
            print("주의하세요 매우 덥습니다.")
        else:
            print("나쁘지 않은 날씨")
    except Exception as e:
        print(e)
        raise e

import boto3
import os
import sys
import uuid
from urllib.parse import unquote_plus
from PIL import Image
import PIL.Image

s3_client = boto3.client('s3')

def resize_image(image_path, resized_path):
    with Image.open(image_path) as image:
        image.thumbnail(tuple(x / 2 for x in image.size))
        image.save(resized_path)
def lambda_handler(event, context): 
    for record in event['Records']:
        bucket = record['s3']['bucket']['name']
        key = unquote_plus(record['s3']['object']['key'])
        tmpkey = key.replace('/', '')
        download_path = '/tmp/{}{}'.format(uuid.uuid4(), tmpkey)
        upload_path = '/tmp/resized-{}'.format(tmpkey)
        s3_client.download_file(bucket, key, download_path)
        resize_image(download_path, upload_path)
        s3_client.upload_file(upload_path, '{}-resized'.format(bucket), key)

1)구축 방법
=>AWS Direct Connect
- 인터넷 우회 전용 물리적 회선
- 일관된 고대역폭 네트워크 품질 보장

- IPSec 기반 암호화 가상 터널
- 기존 공용 인터넷망을 통한 즉각 배포
- Direct Connect 장애 대비 백업 경로

=>AWS Outposts
- 로컬 데이터센터에 내부 AWS 랙 구동
- 극초저지연 온프레미스 로컬 처리
- 동일한 AWS API 및 관리 도구 활용

2)AWS Network 관련 용어
=>Region
- 전 세계에 지리적으로 분리된 거점
- 각 Region은 3개 이상의 AZ으로 구성
- 현재는 33개 정도의 region을 보유

=>AZ
- 독립된 전력, 냉각, 물리 보안을 갖춘 하나 이상의 데이터센터 복합체
- 초고속 전용 광케이블로 서로 연결
- 105 개 이상의 AZ을 보유

=>Amazon VPC(Virtual Private Cloud)
- 논리적 격리 가상 네트워크: AWS 계정 전용의 완전하게 격리된 가상 사설망 공간
- IPv4 CIDR 블록 지정: Private IP 대역을 지정
- 인바운드 및 아웃바운드 트래픽에 대한 포괄적 제어력 제공

=>Subnet & AZ 설계
- Public Subnet
인터넷 게이트웨이(IGW)로의 라우팅이 설정된 네트워크 영역
일반적으로 배치하는 리소스는 ALB, NAT Gateway, Bastion Host 등
Public IP 자동 할당 활성화해야 함

- Private Subnet
외부 인터넷으로부터 직접 접근이 차단된 보호 영역
일반적으로 배치하는 리소스는 Backend Application Server, 내부 캐시, 데이터베이스 등
아웃바운드 인터넷을 허용하고자 하는 경우 NAT Gateway를 배치

=>Internet Gateway(IGW)
- VPC 당 1개씩 연결해서 경로를 지정하고 1:1 NAT 변환 수행
- 완전 관리형 수평 확장: 대역폭 제약이나 가용성 위험 없이 자동확장되는 AWS 관리형 게이트웨이 컴포넌트

=>안전한 아웃바운드: NAT Gateway
- 단방향 아웃바운드 인터넷 통신: Private Instance가 패키지 업데이트 및 외부 API를 호출하고자 하는 경우 사용
- 외부 인바운드 연결 원천 차단
- 준수 사항
배치 위치: Public Subnet 내부에 생성
IP 바인딩: 정적인 Elastic IP 연결
고가용성: AZ 장애 격리를 위해 가용 영역별 각각 생성 권장

=>Route Table
- 서브넷 또는 게이트웨이에서 송출되는 패킷이 이동할 경로를 결정하는 규칙 집합
- 로컬이나 인터넷 게이트웨이 그리고 NAT 게이트웨이에 대한 라우팅 경로를 설정해야 함

=>Security Group & Network ACL(Access Control List)
- Security Group(보안 그룹)
작동 계층: 인스턴스의 가상 방화벽
상태 추적: Stateful(요청한 것에 대한 응답은 자동으로 허용)
규칙 유형: Allow 규칙 만 설정 가능
평가 방식: 모든 규칙을 종합 평가 후 반영

- Network ACL
작동 계층: 서브넷 경계에 있는 1차 관문 방화벽
상태 추적: Stateless(인바운드와 아웃바운드를 별도로 검사)
규칙 유형: Allow 규칙 과 Deny 규칙 설정 가능
평가 방식: 낮은 규칙 번호부터 순차 적용
