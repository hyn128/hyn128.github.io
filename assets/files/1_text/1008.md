	서브넷 연결 탭에서 서브넷 연결 편집을 선택하고 private으로 사용할 서브넷을 선택

=>Customer Gateway
- 온프레미스의 물리 장비
고객사 경계의 라우터 또는 방화벽
AWS 콘솔 생성 시 장비별 샘플 구성 파일 제공

- 고정 공인 IP 바인딩
인터넷 통신 가능한 정적 공인 주소
라우터 외부 인터페이스 정적 IP 필수
NAT Traversal을 통한 Private IP 우회 지원

- BGP ASN 등록
동적 라우팅을 위한 자율 시스템 번호
동적 라우팅을 채택할 때는 64512 ~ 65534 번을 설정
정적 라우팅을 할 때는 기본 ASN(65000) 유지

- Virtual Private Gateway
VPC의 논리적 가상 라우터: AWS VPC 경계에 부착되어 온프레미스로 향하는 모든 VPN/Direct Connet 트래픽의 종단점 역할 수행

하나의 VPG는 하나의 VPC에만 직접 연결 가능하며 다중 VPC 확장 시에는 Transit Gateway를 사용

완전 관리형 고가용성 구조: 사용자가 물리 인스턴스를 관리할 필요없이 AWS 백본 인프라 레벨에서 자동 이중화 및 장애 복구 지원

=> 2중 터널 구조
- Private Active Tunnel
기본 트래픽을 처리
암호화 터널

- Secondary Redundant Tunnel
물리적으로 격리된 별도 AWS 가용영역 B 앤드포인트에 만들어지는 터널
무중단 자동 절체: AWS SLA 99.99% 보장을 위한 필수 요건

=>보안 프로토콜
- IKE(Internet Key Exchange)
통신 양단간 보안 협정(SA)을 맺고 암호화 키를 안전하게 교환하는 제어 프로토콜

- IPsec(IP Security Protocol)
네트워크 계층에서 실제 IP 패킷 페이로드를 암호화하여 기밀성과 무결성 보장

				정적 라우팅						BGP 동적 라우팅
