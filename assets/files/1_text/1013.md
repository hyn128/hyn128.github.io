=>Micrometer 핵심 타입
- HTTP 요청 횟수, 에러 발생 건수, 주문 완료 횟수에 사용하는데 증가만 합니다.
Counter.builder("order.success.total")
.tag("shop", "gangnam")
.register(registry)
.increment();

- 현재 상태에서 올라가고 내려 갈 수 도 있는 값에 이용: 커넥션 풀 활성 수, 메모리 사용량, 큐 대기 길이
Gauge.builder("cache.size", cacheMap, Map::size).register(registry)

- 짧은 지속 시간과 이벤트 발생 빈도를 동시에 측정: HTTP API 응답 지연 시간, DB 쿼리 수행 시간
Timer.sample(registry).stop(registry.timer("api.latency"));

- 이벤트 분포 등의 통계를 집계: 주문 결제 금액 분포
Distribution.Summary.builder("order.amount").register(registry).record(55000);

- 히스토그램: 요청 처리 시간을 미리 정의된 구간(100ms, 200ms) 별로 나누어 카운트

- Percentiles(p95, p99 등): 전체 요청 중 95%, 99%의 사용자가 경험한 응답 속도 이하인 지점을 의미하며 성능 이상 감지에 사용

=>커스텀 비지니스 메트릭 계측 및 태그 관리
- 차원성(Cardinality) 주의 사항
태그 값에 유니크한 사용자 ID, 주문 번호 등을 넣으면 Cardinality Explosion(시계열 폭증)으로 인해 Prometheus 성능 장애가 발생할 수 있음
- 올바른 태그 설계: 결과 상태(status:success/fail), 결제 수단(method:card/transfer) 등 유한하고 제한된 값만 태그로 사용하는 것을 권장

=>METERREGISTRY 주입 패턴
- Spring Component 내에 MeterRegistry를 생성자에서 주입받아 비지니스 로직 수행 전후에 Counter 또는 Timer를 호출해서 다차원 메트릭을 유연하게 생성할 수 있음

=>Controller를 추가: SampleController
import io.micrometer.core.instrument.Counter;
import io.micrometer.core.instrument.MeterRegistry;
import io.micrometer.core.instrument.Timer;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

import java.util.Random;

@RestController
public class SampleController {
    private final MeterRegistry registry;
    private final Counter customVisitCouter;
    private final Timer customProcessTimer;

    public SampleController(MeterRegistry registry){
        this.registry = registry;
        //카운터 생성
        this.customVisitCouter = Counter.builder("app.visitations.total")
                .description("Total number of visits to the sample endpoint")
                .tag("region", "seoul")
                .register(registry);
        //타이머 생성
        this.customProcessTimer = Timer.builder("app.process.latency")
                .description("Timer taken to process sample business logic")
                .register(registry);
    }

    //요청 처리 메서드
    private final Random random = new Random();

    @GetMapping("/hello")
    public String hello(){
        customVisitCouter.increment();
        return "Hello Micrometer & Kubernetes";
    }

    @GetMapping("/process")
    public String processWork(@RequestParam(defaultValue = "100") int millis){
        customVisitCouter.increment();
        return customProcessTimer.record(() -> {
            try {
                int sleepTime = millis + random.nextInt(50);
                Thread.sleep(sleepTime);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
            return "Processed work in simulated time";
        });
    }
}
